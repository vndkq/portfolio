# Junho Lee Portfolio — GitHub Pages

이 폴더는 GitHub Pages에 바로 배포할 수 있도록 정적 파일 방식으로 구성된 포트폴리오입니다.

1. 이 폴더의 내용을 새 GitHub 저장소에 올립니다.
2. 저장소의 **Settings → Pages**에서 **Source**를 **GitHub Actions**로 선택합니다.
3. `main` 브랜치에 올리면 Actions가 자동으로 빌드하고 배포합니다.

저장소 이름이 `username.github.io`이면 루트 도메인에, 그 외의 이름이면 `username.github.io/저장소이름/` 경로에 배포됩니다. 두 경우 모두 경로를 자동으로 처리합니다.

## 학업 이수 현황

공개 GitHub Pages 버전에서는 성적을 포함하지 않았습니다. 성적 조회를 제공하려면 GitHub Pages가 아닌 별도의 인증 서버가 필요합니다.
